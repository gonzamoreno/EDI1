# Carpeta de Fotos (`/fotos`)

Carpeta de conveniencia en la raíz del proyecto para alojar fotos y recursos gráficos.

- Las fotos públicas y servidas en la web se encuentran en [`/public/fotos`](../public/fotos/README.md).
- El servidor `server.js` resuelve automáticamente peticiones a `/fotos/...` buscando en `/fotos` o en `/public/fotos`.
- Consulta [`public/fotos/README.md`](../public/fotos/README.md) para más detalles sobre las convenciones de nombres y formatos admitidos.
